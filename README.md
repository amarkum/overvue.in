# overvue.in

Landing and information site for the [Overvue](https://github.com/amarkum/Overvue) personal finance app. Static HTML/CSS, hosted on GitHub Pages at <https://overvue.in>.

## Structure

- `index.html` — landing page (hand-written)
- `privacy-policy/`, `terms-of-service/`, `support/`, `404.html` — generated by `python3 tools/build_pages.py`
- `assets/` — CSS, scripts (theme toggle; `personalize.js` re-skins the demo phone to the visitor's region — preview any country with `/?region=US`), brand images (the Overvue logo, favicons, home-screen icons and the social share image) and `illustrations/`, the app's spot illustrations in light and dark (re-export from the app repo with `dart run tool/export_illustrations.dart ../overvue.in/assets/illustrations`)
- The phone mockups in `index.html` copy the app's screens and colors (`lib/core/theme/app_palette.dart`); keep them in step when the app's design changes
- `CNAME` — custom domain for GitHub Pages

The app links to `/privacy-policy` and `/terms-of-service` (see `lib/core/constants/legal_urls.dart` in the app repo), so keep those paths.

## Local preview

```bash
python3 -m http.server 8000
```

## Deploy

Push to `main`. The [Deploy to GitHub Pages](.github/workflows/deploy.yml) workflow regenerates the text pages, bundles the site (excluding `tools/`, `.github/` and this README) and deploys it. It can also be run by hand from the Actions tab.

The custom domain (`overvue.in`) and Enforce HTTPS are set in the repo's Settings → Pages; DNS is at GoDaddy (4 A records to GitHub Pages IPs, `www` CNAME to `amarkum.github.io`).
